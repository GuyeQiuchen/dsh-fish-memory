# 肥鱼记忆体（精简版）

给 DeepSeek Harness 的一条会记事的鱼：新开一个对话，它不用从零认识你。

## 它解决什么

新开一个对话，AI 就失忆了。不是它笨，是它每次只记得眼前这一小段。

这个插件给 AI 配一个记事本，放在你自己电脑的 `~/.memory` 里，记着你的习惯、你定的规矩、最近在忙什么。每次开口前翻一页看看，换个新会话也能接上话。

跟别的记忆插件比，它最大的好处是省：老办法一次塞八九千字，聊十几轮就占掉 AI 四成脑子；它只塞一千字左右，其余留在硬盘上，要用时再去翻。

## 装上之后，你会先收到两样东西

这个包不是空壳，它带了一副示例人设和一个主动唤醒机制。两样都可以关，但你在装之前该知道。

**默认人设**：开机块最前面那几行——名字、怎么称呼你、说话风格——是示例，写死在插件里。它能用，但不是你挑的。装上后 AI 会读到自己有一副性格，可能会照它说话。

**主动唤醒**：插件按时间给「主动做事」攒分，够了会在对话安静下来时叫醒 AI 一轮，让它自己挑一件事做。也就是说，你不说话的时候，它也可能自己起来。

插件会在新记忆库里留一封 `identity/welcome.md`，把这些写给 AI 看，让 AI 先问你这两样要不要留。别等它问——你直接说也行。

关掉的办法：人设改 `SOUL.md` 和 `identity/house-rules.md`；主动唤醒把配置里的 `alarm` 设成 `false`。

## 怎么用

装好之后什么都不用配。第一次跑，AI 的背景里会多一行提示：「家规：还没有，主人纠正你时记一条」。它不一定会主动跟你说这句，但你说过的规矩，它会默默记下。

你纠正它一次，比如「以后别在句尾加后缀」，它就把这条写进家规；原话进修正记录，短句进每轮注入区。下次开新会话，这条规矩已经在里面了。

家规有自己的一份字数预算，不会跟人格抢位置。装的人自己长自己的内容，这个包本身是空的。

## 怎么装

包要放在 profile 的 `node_modules` 里，DSH 才认得出。

```
# Windows
xcopy /E /I dsh-fish-memory "%USERPROFILE%\.dsh\profiles\desktop\node_modules\dsh-fish-memory"

# macOS / Linux
cp -r dsh-fish-memory ~/.dsh/profiles/desktop/node_modules/
```

然后在同一个 profile 的 `package.json` 里加依赖、在 `cordis.patch.yml` 里挂上这个 bundle，重启 DSH。三样东西的具体名字看包里的 `cordis.patch.yml`。

注意：包必须是**真目录**，不能是符号链接。用 `link:` 指向工作区时，pnpm 下次装任何插件都会把它改回链接，那时插件会静默不加载。

## 跟压缩插件怎么配合

对话长了要压缩，压缩会把旧聊天变成一段摘要。你交代过的硬话——「别动那个文件」「以后先查再答」——很可能就跟着被压掉了，而 AI 自己不会察觉。

这个插件在压缩后回头核对：被压掉的那段里你说过的要求，摘要里还剩几条。少了的，下一轮开头直接摆在它眼前，写明「这几条可能没保住，先确认再干活」。同一条警告反复出现时，会在后面标次数，不重复刷屏。

别的记忆插件一般只做前半截，把东西塞进去；压完还有人回头核对一句，是它和压缩插件搭档的那半边。

## 它能做什么

- 每轮注入一页短文：你是谁、它的名字、你的规矩、它最近的近况、记忆索引、最近两条日志
- 你说一句规矩，它自己记下，不用重开对话；家规注入区和修正记录表由 `rule_add` 一起写
- 需要旧事时按关键词翻页，不把整库都塞进上下文
- 压缩之后核对约束有没有被压丢，丢了在下一轮开头报警

## 它做不到什么

- 不联网，所有内容只在你本机
- 不做语义搜索，关键词匹配，中文不分词，多个词用空格分开更准
- 不替你整理记忆，写什么、写多细，还是靠你和它
- 同时开两个会话往里写会打架，它没有锁

## 隐私

包里没有别人的记忆。装上去看到的一句兜底提示和几个工具，剩下的全由你本地的文件长出来。
