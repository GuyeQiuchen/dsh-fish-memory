# 0.7.2（2026-11-28）

核对「上次压缩可能压丢的 5 条约束」之后的一版：3 条是假警报，根因在判定正则。

## 根因

约束判定用的是 `/(...|别|...)/`，中文里 **差别 / 别人 / 分别 / 特别 / 区别** 都含「别」，
于是主人问句也被当成「不许这样」的硬约束抓进核对列表；核对自然判「丢了」，
每轮 boot 都挂一条 204 字的警告。

## 修法

`lib/survival.js` 新增 `looksLikeConstraint(text)`：

- 「别」前后排除 `差别/分别/特别/区别/个别/识别/别人`；
- 「不要害怕 / 别紧张」这类鼓励不算约束；
- 长度、忽略自己警告行的规则不变。

`app.js` 的压缩钩子改用这个共享判定，不再自己写正则。回归测试 3 例假警报 + 3 例真命令。
